# 图片预览与托盘改进

图片详情按元数据中的原始宽高比计算可用显示尺寸，保留完整图片并减少多余空白。工具栏有最小宽度，因此极窄竖图仍有对称留白；不会为了填满容器而裁切或拉伸图片。打开的详情仅加载一份原图，关闭后释放引用；列表继续使用缩略图。放大、缩小按钮统一为等宽的 `+` / `−`。

`TrayService` 使用 Windows 原生通知区域 API 和上下文菜单，保留回调委托，并在退出时释放图标、菜单与窗口子类。右键菜单显示 ClipFlow 1.0.0.0、打开和退出。窗口关闭事件在托盘可用时取消关闭并隐藏窗口；后台保留剪贴板监听及数据库服务。退出等待进行中的存储操作后结束进程。托盘创建失败则允许关闭窗口退出，避免不可见且无法退出的进程。收到系统任务栏重建通知后重新注册图标。

Windows App SDK AppInstance 负责单实例激活：再次启动将激活请求传给现有实例并退出第二进程。Debug 的隔离测试目录使用独立实例键，避免测试触碰用户运行中的应用。

标准验证命令：`scripts/Test.ps1 -Integration -BuildOutputDirectory artifacts/tray-debug`。本轮增加四种图片比例、两种窗口尺寸及真实按钮缩放测试；托盘测试包括真实 Shell 图标注册、隐藏窗口中的真实剪贴板保存、实际原生菜单弹出、恢复窗口、重复启动重定向、模拟任务栏重建及菜单退出。验证文档与原始结果位于 `docs/VALIDATION.md`、`docs/integration-results.txt`、`docs/tray-results.txt`。

任务栏重建测试使用同一消息路径模拟重建，没有实际重启 Windows Explorer。UI 图片来自真实 WinUI RenderTargetBitmap 渲染，不包含系统标题栏与 Mica 合成器背景。Release 启动与后台行为另做实际进程冒烟测试。
